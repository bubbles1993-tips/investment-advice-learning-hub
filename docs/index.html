How the hub grows

Keep one hub named index.html, one HTML file per module, and links back to the hub and adjacent modules. Add each new module to the library and progress registry. This keeps individual guides usable on their own and avoids one enormous page.

What works offline?

Each module contains its own styling and learning interactions. A downloaded HTML file can work in a browser that supports local HTML. Hosted access needs an internet connection; a home-screen shortcut alone does not guarantee offline access. Reliable offline phone use would be a later installable-web-app upgrade. Local-file storage and links vary between phone file viewers.
